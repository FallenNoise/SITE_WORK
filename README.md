# Django Blog Project

Простой и функциональный веб-сайт на фреймворке Django для публикации блогов, статей и заметок. Проект создан в рамках изучения веб-разработки на Python.

## 🚀 Функционал проекта

- **Просмотр публикаций**: Главная страница со списком последних постов и страница детального просмотра каждого поста.
- **Фильтрация**: Возможность сортировки и фильтрации постов по дате публикации.
- **Управление контентом**: Полноценный механизм добавления (создания) новых постов через веб-интерфейс и безопасное удаление постов с подтверждением действия.
- **Кастомный интерфейс**: Индивидуальный дизайн, стилизованный через CSS (включая адаптивную шапку, подвал сайта и динамические ссылки).

## 🛠 Технологический стек

- **Backend**: Python 3.x, Django 5.x
- **Frontend**: HTML5, CSS3 (Кастомные стили, CSS-переменные)
- **База данных**: SQLite (стандартная для разработки)

## 📦 Как запустить проект локально

### 1. Клонирование репозитория

```bash
git clone https://github.com/FallenNoise/SITE_WORK.git
cd SITE_WORK
```

### 2. Настройка виртуального окружения

Создайте и активируйте виртуальное окружение:

```bash
# Для Windows
python -m venv venv
venv\Scripts\activate

# Для macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip pip install -r requirements.txt
```

### 4. Применение миграций и создание суперпользователя

```bash
python manage.py migrate
python manage.py createsuperuser
```

### 5. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска сайт будет доступен в браузере по адресу: `http://127.0.0.1:8000/`

## 📂 Структура шаблонов (Templates)

- `base.html` — базовый главный шаблон сайта (скелет, стили, шапка и подвал).
- `pages/index.html` — главная страница со свежими публикациями.
- `blog/post_detail.html` — детальная страница отдельного поста.
- `blog/post_form.html` — форма создания новой публикации.
- `blog/post_confirm_delete.html` — страница подтверждения удаления поста.
